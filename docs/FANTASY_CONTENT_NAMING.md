# 经典来源与显示内容

重要角色与组织优先采用可辨认的文学、神话或历史形象。常见装备、药剂与教材使用清楚的常用词；标志性传奇物品名称留给适合的稀有物品。名称、说明和实际作用保持一致，不因火焰、吸血等字眼新增效果。熟悉程度是编辑判断，尚无美国玩家调查支持。

本批将组织名称集中到 `content/worlds/organizations.json`，由构建器派生原组织的显示名称。每条记录包含原编号、存档身份别名、长短名称、故事主题归属、经典来源、导师引用和审阅状态。中英文使用同一记录；源规则定义与存档编号保持原值。

组织名称、所在故事线与人物来源分别表达。`countries.json` 继续锁定13条国家主线；`origin-countries.json` 登记额外来源，目前有韩国。校验器允许人物或候选来自这些来源，但原剧情引用仍须指向13条已有国家线。来源国家本身不决定敌友关系。

角色对应页将“国家主线”和“其他来源国家”分组显示，统计仍计13条主线。当前没有新增韩国角色、战斗或招募奖励；角色库里的既有映射保持原样。这是接入后续外来角色的内容配置能力，不是已交付新敌人的声明。

地图首页从真实 `adventure.days/timeSlot/sect` 显示日期、两小时时段和组织；使用组织别名处理原古墓的 `古墓` 身份与 `古墓派` 入口编号差异。出师后仍显示原组织身份；读取这些信息不推进时钟或重抽事件。小屏下完整任务说明仍可在 Goals 查看，下一步按钮保持在首屏可操作。

验证包括外来来源接受／未知来源拒绝、主线国家与固定身份保护、组织名称双语投影与原规则逐项一致、12时段边界，以及真实旧存档的加入／出师／存读档。浏览器检查覆盖320×568、375×667、390×844和1440×900，保留实际存档编号与剧情状态。
