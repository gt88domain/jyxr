# 学派与培养改造方案

本文件是下一批界面和内容的设计方案，不是已完成的全学派验收。当前只确认并实施四系与专精术语调整，原入会、教学、毕业和奖励条件仍由宿主执行。

学派是有导师、专属任务和奖励的组织。角色可以选择当前所属组织，主线仍使用原有单一所属状态；持有其他来源教材时是否能学习，继续检查教材自身条件。不能把组织当成排他职业并禁止原来允许的跨流派学习，也不能仅凭新名字就放开原本未满足的导师与任务条件。

选择页首屏显示组织名、两三个实战标签、加入条件与当前可执行按钮。展开详情再列导师、主动技能、被动专精、特殊能力、教材与后续训练阶段。现有 `Techniques` 混合名单只能作为原始特色清单，不能全部视为入会立即发放的技能。未确认身份的导师仍是候选，不能把占位名称称作最终选角。

培养页区分四件事：

1. 研习教材：选择一个当前持有并满足条件的教材，实际参战结算获得经验。
2. 主动技能：拳套、剑术、刃术、法术，按现有启停与解锁条件配置。
3. 被动专精：分别展示学习后常驻收益、装备为主专精后的效果，以及随等级解锁的主动绝招。保留当前一个主专精的规则。
4. 上限突破：单独解释原精通等级带来的等级上限变化、档案继承和一次性领取条件，不与主专精混为一谈。

推进顺序：先完成迷雾学舍和圣杯山舍的来源核对与分栏展示，再逐条接入导师任务、实际训练和结业奖励；每项显示“已可操作”“需条件”或“待改写”，不能只列出原资料就标为已完成。
