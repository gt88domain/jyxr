## 西班牙：风车风波 / Trouble at the Windmill

这次保留原 `白马啸西风_*` 稳定编号，重写人物和事件含义。卡德尼奥、罗克不再被硬套成同一人的假名与真名；战技教官、希内斯、佩雷斯现在是三个不同角色。没有女主父母遇害、神秘身世或师父死亡的结局。

1. 到 Windrider Camp 与女主交谈。她说明自己叫阿尔东莎、骑士称她杜尔西内娅，并在追查失踪补给；猎人、稻草人等先前伙伴仍按原条件影响信任。
2. 原夜间时段（亥、子、丑、寅、卯）有20%事件。跟随她夜巡会遇见盗贼。日常重复回答不增加信任，打开菜单不推进时辰。
3. 战后遇到战技教官。保持冷静、先处理补给增加5信任；额外考核仍按原战斗与减5信任处理，失败后果保留。
4. 回营地时，骑士把村民误当巨人的囚徒；事件仍有30%概率。支持女主增加5信任；支持骑士减少5，扣3道德。不是一个直接选择招募对象的菜单。
5. 信任达到60，女主加入，再一起前往 Windmill Storehouse。入口仍有50%概率；获胜后追回补给、把骗子交给守卫。女主获得原30点、法术+40、生命与能量上限各+500，以及血棘飞矢法术书。
6. 信任不足60，她与村民另行追查；玩家先战希内斯，再解决烟雾中与女主、神父及卫士的护货误会。烟雾仅是对白叙述，不新增Buff。澄清后取得追回的《阿马迪斯》任务书。
7. 独立分支在粮仓内仍有20%概率遇到骑士。对证后可邀请他同行，原道德−2保留；他在结尾才加入，不提前部署到此前战斗。另一结局的女主不能拼进这个存档。

“帮女主”并不保证好感已经足够；低好感也不表示玩家自动成了恶人。两种故事用现有判定分开，游戏没有新增调查面板、证据收集系统、任务变量、额外道具或捷径。

## 伙伴培养与后续

在伙伴页选中要培养的人，检查装备、待分配点数、研习教材与主专精。主专精和教材分别设置。结伴练习只让前两位出场；要培养新伙伴，请把他或她调到第二位。只有实际参战才结算研习经验。

普通女主路线再次实际验证穿戴、分点、主专精、奖励法术的战斗研习与存读档。骑士路线验证真实战斗、诗集原编号对应的新任务书、招募、道德变化、管理与读档。指引不通过传送、补好感或赠送额外物品推进。

原数据中还有“骑士随队才追加宝藏对白”、女主后期成长与其他人物的条件追加段。它们完整的前置入口与英文还未全部接入；不能把人物已招到当作个人故事已做完。改写前的复核见 [WINDRIDER_BRANCH_REVIEW.md](WINDRIDER_BRANCH_REVIEW.md)，其中旧导师结局是历史内容。

## 验证入口

`test_windrider.py` 检查两种语言保留全部非对白流程、地图事件、条件与收益，并检查老师和骗子身份分离、任务书原用途、地点显示一致。全包规则由 `assert_same_flow` 保护，运行包恢复原始规则定义，仅在显示词典中投影新名称。

```sh
dotnet run --project src/Game.Web.Runtime/Smoke/Smoke.csproj -- --three-stories <英文运行包> <完整真实起始存档> <输出目录> first-two
dotnet run --project src/Game.Web.Runtime/Smoke/Smoke.csproj -- --three-stories <英文运行包> <完整真实培养存档> <另一输出目录> knight
```

当前真实存档来源：女主试跑从之前普通开局、教学与24次结伴练习后的6级主角／5级埃尔开始；骑士试跑从既有正常培养后的8级主角／6级埃尔开始。均保留校验值，不是无培养的新建角色通关。

`spanish-windmill-smoke.mjs` 在真正的WebAssembly网页通过普通地图按钮读初遇对白、进入50%入口的真实战斗，检查希内斯的显示身份，再导入两种真实结局检查队伍、任务书、培养提示和390px手机布局。浏览器检查不冒充重新从头打完两条路线；两条完整实战由同一原生宿主的普通玩家指令执行。

困难难度、每个可选切磋、后期支线和实际手机硬件未在这批全面重测。此前旧剧情的普通／困难测试留作历史记录，不能套作新章全部验收。公开实录明确分开新版西班牙、法国复测和旧意大利尝试。

## 其他已知边界

法国最后一战原先漏执行必选名单；普通宿主现在先为已在队中的必选成员预留名额，再按队序补齐。完整普通试跑三战分别18、56、40次操作获胜；最后一战实际为主角、霍青桐、陈家洛（新版米莱狄、达达尼昂）。塔楼消耗3瓶原有药剂，最后一战未用药。主角从此前真实教学与培养后的6级开始，经西班牙章与8次伙伴练习，法国招募时10级、最终入场前11级；不是未培养开局即可通关的证明。达达尼昂按原配置16级入队，原版数据与收益未改。

`french-party-smoke.mjs` 从此次未编辑的 `france-finale-ready` 存档通过真实地图按钮进入WebAssembly战斗，核对战前招募和三名实际参战者，再检查真实结局存档。完整战斗由原生共享宿主执行，不声称浏览器又从头打完所有战斗。

意大利的最后一战原本只让主角出场，旧试跑两次失败。没有补发匹诺曹、改变敌人或自动重开入口。后续按国家原著人物重新写剧情，需要分别交付，不能声称此次西班牙改写已经完成其他国家。
