# 现有界面盘点与逐批替换

按交互用途计 **27 类核心界面**，不是27个URL；对白分支、选项卡、桌面与手机尺寸不重复计页。清单的代码入口是 `src/Game.Web/src/ui-surfaces.ts`。本批已拆出地图首页、组织选择、目标页及组织进度模型；仍通过同一套真实宿主操作。旧版独立入口、冻结数据与战斗数值不改。

| 类别 | 页面 | 当前入口与处理 |
| --- | --- | --- |
| 场景 1–4 | 标题／继续、创建角色、本地探索、世界地图 | 本地探索拆到 `world-dashboard.ts`；地图继续复用原 atlas |
| 场景 5–8 | 对话／选项、战斗／结算、买卖、组织选择 | 组织选择拆到 `academy.ts`；其余保留真实交互 |

## 首屏约定

- 手机底部常驻：人物、背包、队伍、目标、地图、更多；保存和通知保留在顶栏。
- 地图首页先显示地点、生命／能量、真实下一步、装备／主专精／研习摘要，再列人物与地点。常用操作44px触控区域；低频说明、完整目标与历史放到展开区。
- 下一步只能打开原有面板或点击当前地图真实可用的地点；不传送、不补标志、不重抽事件。目标页导航前关闭弹窗，避免对话藏在弹窗后。
- 地图按钮滚到当前地图的地点区，不额外推进时间。装备／研习可直接打开冒险者手册；详细技能仍可从更多查阅。
- 320、360、390、768、1440px检查溢出；320–390px检查下一步与底栏确实位于首屏。更长的物品、人物姓名允许换行。

## 本批实际走的组织路线

新建普通人物 → 格林开场与赠书 → 穿练习武器、选专精与研习 → 木人练习实际胜利 → 买药教学／真实购买 → 学徒战 → 选择圆桌骑士团 → 原训练／来访切磋 → 原天数门槛出师、疯帽匠加入 → 雪地 → 下山 → 大地图 → 存读档。

圆桌骑士团对应原大轮寺。原条件 `elapsed_days > 60` 使用**冒险总天数**，不是加入后的60天。训练本身推进一天；达到门槛后仍需执行训练分支触发出师。出师开放山道，保留组织身份；没有新增“退出组织”命令。来访切磋输赢仍走不同原分支，不把胜利变成额外的出师条件。

`chapter-academy.json` 只定义显示、地图指路和13段对白改写；训练奖励、切磋胜负、出师奖励和加入条件不变。疯帽匠采用原角色表中达尔巴已有候选身份，接入本段显示；其他中后期台词仍待逐段改写。其余八条选择保留，未宣称已逐条通关。

## 验证

`Smoke.csproj -- --academy-journey <worlds运行包> <隔离输出目录>` 从真实问答开局运行上述全过程，输出未经编辑的检查点与SHA256。失败时保留当时状态；不使用剧情跳转、改日期、改存档或指定胜负。`guided-interface-smoke.mjs` 在真实WASM中走可见新手准备与导航，再导入带校验的真实检查点验证组织选择、一次实际教学、临界日出师、伙伴管理、下山及存读档。原始进程与浏览器的验证范围分别记录，不把检查点导入称为浏览器从头全程通关。

现代版队伍页已拆到 `party-roster.ts`：队伍顺序、装备数量、未分配点数、主专精与研习摘要优先显示；装备、专精、研习三个44px快捷键先选择对应伙伴，再直达现代手册相应区域。后备、剧情随行、暂离和道德说明放到下方展开区。正常编队只显示顺序，不承诺固定出场人数；战斗中依据实际单位标记本场是否出战，未出战与后备状态分别呈现。旧风格保留原面板。

下一批优先：背包用药、商店买卖；然后属性天赋与战斗信息层级，再处理低频仓库、设置与结局。原素材暂用，未制作整套新立绘和战斗特效。
