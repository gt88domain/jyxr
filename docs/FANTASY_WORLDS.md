## 统计口径

冻结的原包包含 513 个角色定义、413 种显示名。按有依据的身份合并成长形态后，对照表包含 417 组实体：308 组剧情人物、86 组兵种／动物等通用模板、22 组系统对象和 1 组玩家。不是 513 名可招募伙伴。

剧情人物中，25 组核心身份固定，283 组为待审候选。候选库列出 474 名既有人物，当前命名原创角色为 0。招募目录覆盖 65 个原定义形态、63 种显示名、62 组身份；这是当前目录的引用覆盖，不声称所有剧情条件已经可达。

身份合并依靠原编号、已知别名和剧情证据，不能只看显示名：

- 阿九拜师获法号九难，原剧情的离队／入队命令也相互对应，因此保留两个定义、共用一组身份。
- 长安深夜的三种神秘女子形态后来揭名霓裳，共用身份；另一个名为练霓裳的定义不凭名字相似强行合并。
- 温家五兄弟的原显示名有重复，五个定义仍是五个人。
- 不同的蒙面人、神秘人不会因通用名称相同而合并。

证据入口和具体原剧情编号记录于 content/worlds/identity-notes.json。每个原定义保留完整定义的 SHA-256，用于检查基础规则是否被误改。

## 选角与审阅

先找适合该国主题、剧情位置和战斗形象的知名文学、传说或历史人物。确实没有合适既有人物才使用命名原创，必须记录真实缺口原因。普通士兵、动物和物件是模板，不伪装成命名原创角色。

已固定身份不能被脚本自动重新分配。待审候选不表示剧情、性别、关系和能力已经适配；表中分别提示叙事与战斗适配、形象调整和地域知名度等问题。知名度分为广泛／类型受众／地域受众，只是编辑估计，不是调查排名。

来源列区分原始作品、神话、民间传说与历史。选取基础人物不等于可以使用任何现代影视形象、译文或美术；后续素材需要逐项记录来源。这里没有使用现代改编电影的图片。

## 数据与工具

数据位于 src/Game.Web/content/worlds：

- project.json、countries.json：项目阶段、备份、十三国结构与设计边界。
- figures.tsv、figures.json、source-labels.json：既有人物库、双语姓名与来源标签。
- cast-map.json：持久化角色身份、国家、候选状态、原定义形态与摘要。
- legacy-index.json：所有 513 个原定义到身份的索引。
- locked-identities.json：25 组固定身份注册表。
- identity-notes.json：别名与合并证据。

seed-world-cast.py 只用于首次建立草案，不是普通构建步骤；不得通过重跑种子脚本洗掉人工审阅。正常构建只读取已经保存的映射。相关国家由原剧情说话人、命令参数和战斗引用推导，尚不等同完整条件求值或路线可达性分析。

在 src/Game.Web 运行：

    python3 scripts/world_cast.py
    python3 scripts/build-world-catalog.py
    python3 -m unittest discover -s tests -p test_world_cast.py
    node tests/world-cast-smoke.mjs

浏览器检查需要先用 4214 端口服务 artifacts/fantasy-worlds-site；可用 WORLD_CAST_URL 指向其他地址。构建还生成逐文件核验的 artifacts/fantasy-worlds-cast.zip。

双语页面支持国家、原名／新名搜索、可招募引用、固定／待审筛选、成长形态详情和 CSV／JSON 导出。中英切换保留筛选和身份。手机首屏保留主要搜索和首个人物，不常用说明收在展开区。审阅工具不读写旧游戏存档，也不创建游戏数据库。英文页面保留原中文编号以便核对，这不表示原对白已翻译。

## 下一步边界

按国家逐批审阅人物关系与技能形象，再接入显示层的本地化内容包。剧情条件和稳定编号沿用，玩家可见的姓名、对白、描述、地图标签分别替换，不进行全局字符串替换。随后制作并替换人物、地图、装备图标、战斗动画、特效和音频。当前审阅页只使用文字与字母图形，没有交付新游戏美术。

战斗、装备、修炼与存档继续复用现代宿主，玩法数值不因换名字而改变。完整国家章节需要单独验证入口、奖励、招募和回档；本次角色工具的检查不能代替完整游戏验证。
