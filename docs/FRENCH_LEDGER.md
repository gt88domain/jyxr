# 法国章：枢机主教的账册

本批沿用西班牙章的改编原则：保留原事件骨架、稳定编号、条件、战斗、招募时机和奖励，重写玩家看到的对白。法国章仍从蔷薇商队开始，经枢机塔救援，回到商队决战；没有新增调查面板、分支、物品或拜师门槛。

## 人物关系

米莱狄是有手腕、有私心的情报人物，不再写成普通善良商人。她掌握账册里的款项与人名，罗什福尔要收回记录并控制证人。玩家答应救被关押的信使，米莱狄以双方利益暂时一致为由同行。她没有悔改或宣誓效忠，也没有因一句对白新增背叛判定。

达达尼昂敢冒险、重承诺，对米莱狄保持警惕。他在塔楼负责带出信使，因此塔楼对白中出现不等于已经加入战斗队伍；正式招募仍在商队决战前。决战时是共同对抗眼前威胁的临时合作，结束后他愿意继续同行，但不会突然把米莱狄视为可信挚友。

罗什福尔以抓回信使、账册和证人为目标，不再每次都围绕预约、薪水和预算说笑。幽默主要来自米莱狄的委婉威胁、达达尼昂的直率和互相戒备；紧张场面仍保留威胁感。

以上是取用大仲马人物性格的幻想支线，不是《三个火枪手》的原著事件复述。米莱狄与达达尼昂在本章暂时同行属于游戏改编，不暗示原著中两人本是友好同伴。人物身份和显示映射均保持既定版本。

## 原著用语与验证边界

“All for one, and one for all!” 是《三个火枪手》第九章结盟格言的常见英文表达；此处为通行格言用法，不引用某个现代译本的独有句式。其余本章对白均为游戏新写，包括“并肩可以，把后背交给她还需慢慢来”等笑话，不冒称原著名句。

`chapter-three-tales.json` 中法国九段改写与法国指引由本批更新，意大利键未改。全包 `assert_same_flow` 检查两种语言的非对白命令、条件、奖励、战斗和地图数据仍与冻结包一致。内容静态检查不能代替指定阵容修复后的实际战斗；是否通过该战斗，以本批宿主测试和实录为准，不沿用旧错误阵容的通关记录。

本批普通试跑从校验值为 `1d14362037a59528ee86e91b76cd6aabe218cadd6a5dc8642cf25fd471d991e8` 的真实培养存档开始，经过西班牙章与8次伙伴练习后进入法国。三战分别18、56、40次操作获胜；最后一战实际部署主角、米莱狄、达达尼昂，原奖励和存读档通过。浏览器另从真实决战前存档点击地图进入战斗，验证战前招募、部署、手机界面与结局导入。困难难度和完整原版难度一致性没有因此得到验证。
