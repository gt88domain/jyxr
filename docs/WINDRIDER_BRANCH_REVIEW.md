## 骑士的好坏与直接对白

原角色陈达海在游戏营地场景中明确伤害部落民众、以寻宝为目的，是恶徒。新版堂吉诃德使用理想主义、误认敌我、鲁莽与承担后果的方向；不能因沿用了相同编号就说塞万提斯的堂吉诃德原著也是这个恶人。

当前营地有直接交锋：骑士把村民当成恶人，女主纠正他，说明同行寻宝者已伤人，请玩家阻止他们。低信任分支的后续中女主不在队，骑士入队段自然没有新增她的随队对白。本批没有杜撰双方同时入队的闲聊。

这是游戏新写对白，**不是原著名句**。杜尔西内娅在《堂吉诃德》主要是骑士理想化的意中人，并没有本游戏这套亲自施法、导师与地宫的经历；本章骨架来自《白马啸西风》，不是复述塞万提斯小说。当前双人关系仍很短，不能说已做出完整经典关系场面。
