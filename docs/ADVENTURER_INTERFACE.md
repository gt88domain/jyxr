# 冒险者手册：第一张界面示范

这是接在真实 HTML5 游戏上的角色／装备／培养页。入口是新版现代菜单的“人物”，或游戏 URL 的 `?screen=loadout`；继续已有旅程或结束开场对白后会打开当前真实人物。地图首页与组织选择的后续替换见 [界面盘点](UI_MIGRATION.md)，战斗继续按现有方式运行。

视觉方向采用清晰的战术 RPG 信息分区、蓝绿与暖金配色、纸张底色和装备图标框。RO 可参考角色与图标的亲和力；童话题材并不等于 RO 的职业、画风和界面。欧美与日本 RPG 玩家已有的装备栏、主动技能、被动搭配和角色切换经验，是本页的布局依据；尚未做地域玩家偏好调查。人物与物品图仍使用当前资源，不把这次界面示范当作美术替换完成。

桌面同页展示人物、装备、已装备被动专精、主动技能和研习教材。手机缩成角色摘要与可触控卡片，首屏显示当前专精名、武器与攻击／防御读数；页面内的准备步骤可以定位到装备、专精和研习区。所有按钮使用原有宿主操作，读档后显示真实人物，示范页没有另一套独立角色数值。

## 名词

| 对象 | 英文 | 本作示例 |
| --- | --- | --- |
| 技能本身 | Skill / Technique / Spell | Hearthward Fist、Bloodthorn Bolt |
| 被动专精本身 | Mastery | Steadfast Mastery |
| 战技与专精教材 | Manual | Hearthward Fist Manual、Steadfast Mastery Manual |
| 法术教材 | Tome | Bloodthorn Bolt Tome |
| 教材总称 | Learning guide | UI 的 Study 区 |

Scroll 是正常的奇幻词汇，但经常表示一次性施法卷轴；本作的教材保留在背包，选择后随实战获得经验，Manual／Tome 更贴切。暗黑1区分学习法术的书和施法卷轴；暗黑2、4的主要技能成长使用等级与技能点，不能把整个系列概括成读卷轴学技能。本作仍保留原来的研习规则。

`rpg-guides-v1` 命名策略只改变显示包中教材的名称、说明和相关教学文案。运行包的规则定义、内部编号、武功名称匹配、物品效果与条件仍为冻结原值；技能和物品同名时继续使用分类词典。

## 新手重做的边界

用户本轮明确要求新手至少有装备与功法。因此新版通过 `browser.starterEquipmentId = 木刀` 在新建人物时补齐一把原有低级练习武器；问答已有同物品时不再叠加，重摇也不累计。原人物定义已经学会基本内功，显示为 Steadfast Mastery；格林原位置的赠书和剧情奖励继续保留。普通、困难模式都有实际武器和原有基础专精。

这项开局配置只存在新版包，原版包没有补发。继续或导入旧存档不补物品；后续周目问答不重复追加这项新手配置。原剧情链、加入条件、概率和战斗数值没有修改。

已超过教材教学上限的人物，会看到“本书已掌握”与明确原因，不能再被要求点击一个无法生效的研习按钮。新版的研习教学目标也认可已掌握的教材；实际技能等级不回退，旧的学习经验不清空。

## 验证入口

`Smoke.csproj -- --onboarding <新版运行包> <原版运行包> <未编辑旧存档> <隔离输出目录>` 检查两种难度的新建角色、重摇、真实换装与研习、存读档、原版开局不受影响和已学完教材的状态。保存的正常人物由 `adventurer-sheet-smoke.mjs` 导入后，通过可见按钮验证新页的穿戴、研习、主专精、预览入口、390px布局与旧存档状态；不会编辑玩家存档来凑界面。

`test_learning_materials.py` 检查名称分类、双语文案、保留原问答奖励、仅允许已批准的低级开局装备，以及运行包规则定义不被翻译覆盖。
