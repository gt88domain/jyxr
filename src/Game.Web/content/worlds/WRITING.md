# 新版对白写作约定

美式英文（en-US）是主要发行文案，中文提供同义对照。采用美国玩家熟悉的短句和词汇：Armor、Defense、Traveler、Practice、Heavy Weapons。内部编号及原专有名词不参与全局替换。直接围绕新角色和当前任务创作，不沿用金庸对白逐句换名。改写可以调整纯对白长度；剧情编号、选项目标、条件、战斗、发奖和存档引用由共用规则管理。

幽默来自角色目的、性格冲突、具体情境和意料之外的反应。保留认真、紧张和安静的段落；不要求每句话都是笑话。笑点之后，玩家仍应清楚下一步找谁、去哪里、操作什么。教学说明和物品描述先核对实际效果，不为了笑话许诺不存在的功能。

世界直接作为开放的幻想冒险呈现，开场后让玩家探索、结识伙伴、培养组合。不强求给每次相遇补动机，也不为新身份发明招募任务。原道德值、物品、队伍、战斗与阶段条件一律保留；有依据才在对白中提示，导航给出地点，不必写容易与地图冲突的方位。

## 口吻

- 格林：本作虚构的故事搜集者，以历史作家为基础，不冒称作者真实言论。谨慎、关心旅人，偶尔拿自己的文书工作和缺乏战斗经验自嘲。他召唤玩家，是请玩家帮助各国童话中的人；不另加恶魔主线或固定国家总数设定。
- 主角：普通旅人，机灵但有同理心。可以质疑任务安排，遇见危险也会紧张；不以嘲笑一切代替个性。
- 西班牙章：堂吉诃德善意、执着、会误认现实，不能知情作恶后毫无反省；杜尔西内娅用阿尔东莎的朴实独立身份解释，法术与同行能力属于幻想延伸。希内斯是狡猾盗贼，教官是独立功能人物。原著短句、现代自译和新写笑话须分清，出处见西班牙章说明。
- 法国章：米莱狄逐利、擅长操控，不写成普通善良商人；达达尼昂勇敢重承诺，同时保持戒心。两人的临时同盟属于幻想支线，不宣称原著里本是友好同伴。罗什福尔保留威胁感，不能每次只拿文书工作开玩笑。
- 教官：普通功能角色。务实，有多年训练经验，冷幽默围绕站位、纪律和训练。战术说明必须准确；训练假人会攻击，不应写成不会还手。
- 店主：普通功能角色。精明、坦率，笑点来自算账和旅行者的宏大抱负。买卖规则以实际价格、库存和效果为准。
- 爱丽丝：参考卡罗尔原著的好奇心、礼貌、认真追问荒诞规则，以及偶尔的急躁；不套用现代影视的战士身份或台词。
- 德古拉：参考斯托克原著的礼节、控制欲、危险和自尊。幽默可以来自过分正式的待客方式，不把他持续写成无害谐星。
- 索尔：参考北欧神话的直率、力量、好胜与易怒，给他显出勇敢与担当的时刻；不复制漫威形象与口头禅。
- 匹诺曹：参考科洛迪原著的冲动、轻信和逃避功课，以及逐渐学会负责的过程；不只围绕鼻子写笑话。
- 哪吒：以传统故事的反抗、勇气及复杂的亲情冲突为基础；不使用现代动画电影的独有造型、设定和标志性台词。

知名角色尚未接入的对白，仍标待改写。人物表的 proposed 身份必须先审核；木头人属于训练道具，不占用尤瑟等知名人物的身份。普通教官和店主也不强配文学人物。

## 当前接入范围

`grimm-skin.json` 保存格林六句开场、全部新手村问答、教官教学与首战提示、首次商店介绍和结伴练习。它通过 `chapters` 加载 `chapter-start.json`，补出村买药、四种赠书、切磋和恶霸两条训练分支、胜负后续、埃尔的招募与寻宠对白，以及九个门派全部入口和选项闭合。`chapter-companions.json` 接入已定名的20个招募身份及关联说话人，改写22个现有加入相关剧情段，另两段已归入完整法国／意大利章节；不往纯命令加入段和测试段添加对白。`chapter-windrider.json` 补齐白马线全部剩余对白、选择及3段女主跨线后续。`chapter-academy.json` 提供组织培养与毕业后续；`chapter-three-tales.json` 完整改写法国9段、意大利15段及格林来信。合计专门改写164个剧情段、516句新版对白。其他中后期招募前置路线和门派后续修炼剧情仍待改写。寻宠后续保留原中期前提和概率，不承诺新手阶段立即完成。

伙伴名单从原包加入／跟随命令提取，记录62个身份、65个形态，包含特殊及测试记录。身份是否固定、名称是否接入、加入场景是否改写是三件事；当前20个已定名招募身份全部换名，另42个仍为候选，其中部分名称已在游戏使用。生成的伙伴CSV提供逐项对照，不能把记录总数说成全部正常可招募或全部路线已完成。完整说明见 [FANTASY_COMPANIONS.md](../../../../docs/FANTASY_COMPANIONS.md)。

第一条小说路线是《白马啸西风》对应的风骑者之旅。两个结局保留不同奖励、好感条件与招募结果；不能把低好感分支也写成女主加入。本章已按批准方案改为补给失窃、骑士误判与风车粮仓；原华辉显示为普通战技教官，瓦耳拉齐显示为希内斯，二者不再是同一人的假名与真名。删除父仇、养父与导师死亡文案，见 [SPANISH_WINDMILL.md](../../../../docs/SPANISH_WINDMILL.md)。法国《书剑恩仇录》线已按互不信任的临时同盟改写，宿主修复必选部署后以主角、米莱狄、达达尼昂实际完成普通终战；这不等于全部原版难度一致。改编边界见 [FRENCH_LEDGER.md](../../../../docs/FRENCH_LEDGER.md)。意大利《鸳鸯刀》线已由同一正常新档链、调整实际补给分配后手动打通善线，匹诺曹按原剧情加入；旧失败保留，稻草人分支未验。最新证据见 [BATTLE_READABILITY_ITALY.md](../../../../docs/BATTLE_READABILITY_ITALY.md)，[THREE_STORY_PLAYTHROUGH.md](../../../../docs/THREE_STORY_PLAYTHROUGH.md)保留历史实录；流程、窗口限制及测试边界见 [STORY_CHAPTERS.md](../../../../docs/STORY_CHAPTERS.md)。

`segments` 替换等长对白；`dialogueEdits` 替换经校验的连续对白段落；`choiceText` 只改选项文字；`definitions` 只改明确允许的名称和说明；`locations` 只改地图地点的显示名与说明。`creationText` 只改七道题及答案文字，原属性、物品和奖励保留。章节文件锁定同一源 SHA，重复键冲突会阻止构建。校验对技能参数、物品效果和条件、奖励、选项分支及地图坐标进行原值比较。不要全局替换剧情字符串中的名字或参数。

编辑显示包用于三列文案审阅；真正交给宿主的运行包保留全部原始规则定义，将新名称和说明放入 `browser.displayCatalog`。只在前端明确的显示字段上投影，避免原技能名称匹配规则失效。英文 UI 字典和模板在 `src/ui/`；新版中文对照同时使用幻想题材术语，原版应用、内部编号和操作参数不参与界面翻译。地图目的地改名不等于其所有后续剧情已完成。检查报告必须区分对白覆盖、静态流程保留和实际走过的路线。

前期统一使用拳套、剑术、重武器、法术、被动专精、手册、法术书与药剂等名称。拳掌对应拳套，奇门对应法术，内功对应被动专精；当前装备的主专精与教材研习分别设置。技能本身不叫 Scroll：战技与专精教材用 Manual，法术教材用 Tome，教材统称 Learning guides。`rpg-guides-v1` 在显示包统一教材命名，不能覆盖运行包规则名称。光辉／幽影亲和对应原阳／阴数值，只改变呈现，不增加元素状态。低级掉落与装备词条也须检查，不能只给固定商店货品换名。完整短章的测试路线与验收边界见 [FIRST_LOOP.md](FIRST_LOOP.md)，名称示例见 [TERMINOLOGY.md](TERMINOLOGY.md)。

`chapter-equipment-copy.json` 明确提供97个原有解锁招式的完整名称，以及随机装备天赋池缺少的11项名称与说明。它们只进入显示词典；不拼接部分中文名称、不改变解锁与词条概率。随机装备使用的14个天赋现均有对应文案。界面词典中的技能别名须与基础技能／被动专精名称一致，物品与技能同名时仍按各自类别显示。
