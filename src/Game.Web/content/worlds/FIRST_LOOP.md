# 前期闭环试玩

[英文试玩](https://gt88domain.github.io/jyxr/fantasy-worlds/game/) · [新版中文对照](https://gt88domain.github.io/jyxr/fantasy-worlds/game/?lang=zh-CN)

建议从新建旅程开始，选择普通难度。正常使用自动或手动战斗均可；这个短章的推荐路线是「独行道路 / Independent Traveller」。其他学派会进入更长的培养路线，不属于本次短章验收。

1. 和格林交谈，领取坚毅专精卷轴，进入旅人村。
2. 在装备页穿戴已有装备，在研习页选择坚毅专精卷轴。若出身没有初始装备，先做其他准备，之后到十字镇买长袍。药剂、装备和卷轴都使用真实背包；普通难度的启程药剂可在行囊使用。
3. 找教官选择练习，实际完成首战，再退出教学菜单。首屏训练目标按原规则要求实际获胜，落败不会完成目标，可以在离村前重试；胜负与奖励照旧。
4. 回格林屋内，询问出发并接受实地教学，领取原任务的300银币。
5. 前往十字镇补给铺，选择四类赠送卷轴之一、领取五份恢复药剂，再实际购买至少一件商品；缺装备可以在此购买护甲。
6. 回格林居所交差，选择小学徒切磋或恶霸挑战，实际战斗后返回交差。
7. 选择独行道路，再去药师谷帮助埃尔，邀请她入队。寻宠的中期后续不是本章的完成条件。
8. 回格林居所，选择结伴练习。主角与埃尔实际参战并获胜；落败时可以调整装备、卷轴和战斗方式后重试。
9. 阅读实地笔记，保存。刷新后继续旅程，检查伙伴、装备和卷轴是否保留；目标页与首屏指引应显示9项全部完成。

首屏指引读取宿主实际目标，不自动完成任务，也不跳过地图条件。已进行过前几步的存档可继续；从中后期存档开始不能验证开场闭环。原版应用的存档独立保留，切勿用测试导入覆盖自己的备份。

本次覆盖前期人名、选项、技能、被动专精、卷轴、药剂和常见装备命名，名称与说明已覆盖当前包的158项基础主动技能、43项被动专精、347种道具、27项特殊能力和33种状态，另保留先前6项组合技的换名。稀有高阶装备词条、更多学派路线及中后期故事仍需后续批次；原素材暂时沿用。
