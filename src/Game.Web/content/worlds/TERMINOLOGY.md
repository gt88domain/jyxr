这是对现有玩法的题材呈现：改成拳套、法术和被动专精不会额外制造燃烧、冰冻或独立魔法伤害类别。原技能范围、亲和、消耗、效果和奖励保持。卷轴研习与当前装备的主专精是两个真实操作；道具说明按原效果标明恢复量、永久属性或装备要求。

完整名称保存在 `grimm-skin.json`、`chapter-start.json` 、`chapter-guide.json` 和 `chapter-us-catalog.json`；[三列文案与流程对照](https://gt88domain.github.io/jyxr/fantasy-worlds/review/)用于逐条审阅。

玩家确认的整系对应：拳掌 → 拳套 / Gauntlets；奇门 → 法术 / Spells；内功 → 被动专精 / Passive masteries。剑术保留，刀系对应重武器，不增加射术成长线。主专精的装备状态与教材研习分别选择；学习收益、装备后效果及由专精解锁的主动绝招均保留原规则。角色与装备的四系加成也使用这组对应，不单独将拳套加成误标为施法。

法术改名不代表整系伤害已增强，不新增元素抗性或移动持续施法规则。平衡调整等完整跑通后再讨论；本轮不修改任何威力、消耗或控制参数。英文中的 `Mastery` 表示被动专精，教学奖励中跨存档提高等级上限的原“精通”称作 `Proficiency`，避免与装备主专精混淆。
