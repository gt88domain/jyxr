# 原版90%阶段交付

当前约90%为工程估算：六项加权88，沿用按5%取整的口径。它不是通关率、测试覆盖率或旧版全行为等价比例；没有完成100%。仍使用现代C# WebAssembly规则内核和HTML5前端，原版优先，西方试验章没有扩大。

## 本轮交付

- **伙伴与剧情条件**：65形态、80条JOIN/FOLLOW指令和155条原路线全部保留。219个条件与实际剧情共用编译器，图鉴显示当前是否满足；随机条件不在查询时抽签，后续节点仍在实际执行时重新判断。
- **地图前置**：补32处地图的静态连接及剧情传送。阿九路线现会显示公主寝宫需经天安门、龙游帮传送，以及船老大入口的接黄金3、皇宫太后7等条件；不会把局部NPC条件当作完整可达条件。所有条件仍受原事件优先级、重复记录与概率控制。
- **独立图册**：[65形态的原版招募图册](ORIGINAL_COMPANION_ATLAS.md)含155幅Mermaid路线图、入口优先级、地图解锁与离队记录；游戏内可下载同一份Markdown。
- **正常路线**：从此前未编辑的26级旅程继续，以实际地图行走、原对话选择及战斗招募阿朱、郭襄、袁承志和韦小宝。普通流程已验证14名；本轮路线增加5场战斗，4胜1负，实际战败分支也保留。累计报告59场、47胜包含前批历史，不是本轮新跑59场，更不代表全游戏通关。
- **自动战斗**：评价缺血治疗、全队强化、已有状态、净化、怒气/集气和自伤；避免满血浪费治疗、无效果控制和最后一人无收益自杀。安全数值预览包括确定性Hook和随机倍率中点，不消耗实际随机数。与位置无关的评价只在一次候选生成中缓存，跨行动不复用。随机天赋及全部组合仍非完整期望模型，也不声称复制旧AI。
- **MP与反弹**：精明溢出的MP伤害先排队，再由普通保护、反弹、不老长春决定取消或落地。反弹HP/MP使用原float四分之一；反弹致死进入保命/复活链。保留旧BattleField接收已取消AttackResult时真气护体的零MP代价分支。阵法分伤的延迟死亡时点仍未全部等价。
- **伤害特技**：一刀两断、襄儿的心愿、火枪、同归剑法、天地同寿、腐尸毒、过肩摔、神龙摆尾接入命中、反弹、阵法及反应。通过内容配置区分原顶层特技分支和GetAttackResult早退分支；普通公式中的伤害上限、宝甲、易容保护不会错误套到这些原特技。技能状态在有效命中后应用。自伤、多目标、负伤害和全部旧回调时点仍待核对。
- **招式演出**：102个原动画ID绑定8类可配置HTML5矢量演出，真实SkillCast提供目标与完整命中格；单次绘制最多48格。暂停覆盖Tween、场景时钟与角色帧，减少动态效果保留简化反馈；败退使用受击和淡出。此为现代演出，不宣称已复刻原Unity粒子与全部时间线；原角色素材、动作和183段音频继续使用。
- **保存恢复**：独立自动进度在稳定地图边界记录，手动存档另存，标题页可分别读取。关闭自动保存生效，写入失败保留旧档并明确提示，正常行动不会假装回滚。独立设备档案与两世界隔离继续保留。战斗/对话中的无悔实时存档仍缺。
- **构建**：改为Release托管程序集，保留反射，不启用裁剪/AOT。`runtime/build-info.json`记录实际文件体积；本次约48MB含预压缩副本，未声称Release显著缩小下载。后续仍需实测启动、长时内存与更多浏览器。
