# 原版资料馆与版本补充

最新后期核对：[X1.1.0.6具体差异](X1106_COMPARISON.md)。新增后期工程自带23份打包XML、实际Unity界面预览及编辑器/模板三方比较，纠正“模板一致即可覆盖后期”的范围误判：107条奥义的额外威力与工程打包值不同，御剑有天山剑法12级授予引用；另四项仅找到说明。原资料馆与已接入玩法继续保留，这批没有覆盖现有战斗数值。

本轮优先补全资料，不做通关测试，也不以资料条数提高游戏完成度。浏览器仍使用现代 TypeScript 界面与 C# WebAssembly 内核；参考快照不会作为旧版脚本执行。

## 伙伴数量口径

原迁移基线中有 **63 个显示名、65 个含 JOIN/FOLLOW 指令的角色形态**，共80条加入／随行指令。包含阶段形态、随行和调试参考，不等于65名普通可招募伙伴。此前的“10名”仅为连续普通流程已验证的数量。

上传的 X1.0.0.1 包还包含双儿加入段 `鹿鼎剧情4.4`，但基线、上传包、官方早期、后期模板及重制Excel角色表均未找到双儿人物定义。现单独列入“缺定义伙伴”，没有编造属性。加入指令参考共涉及64个显示名、66个对象标识，其中双儿缺定义且入口未接线，不能称为66个完整伙伴形态。

进一步核对后期Lua，发现 **43个多周目开局随机奖励候选**，其中只有丁春秋、慕容博、阿九3个ID与65个剧情加入形态重叠，另有40个ID此前未计入剧情图鉴。两种来源合并有105个ID，再含双儿补充指令共106个引用对象；不是106名已完成招募的伙伴，也不是不同人物的精确人数。奖励池“白眉鹰王”的称号引用现已修正为现有角色“殷天正”，依据是原 `skills.xml:492` 的鹰爪功说明“白眉鹰王殷天正的成名绝技”；保留角色属性，原快照不改名。

原 `RollRoleUI.cs` 的周目调用关系与 `rollrole.lua.lua` 的候选池相互印证：第一周目为空，第二周目17个，第三周目10个，第四周目7个，第五周目起9个；从对应非空池随机抽一名。网页已接入这项奖励：预览展示本周目候选，确认人物时只抽取并加入一名，重摇、返回、取消、导入和读取存档不发放。同周目重开会重建新队伍并按该周目池抽一名。伙伴由真实PartyService创建，沿用原人物属性、武学与装备，不编造剧情加入记录。

保留原抽取权重：`RollRoleUI.cs:712` 使用 `GetRandomInt(0, Count) % Count`，`Tools.cs:45-48` 的整数上界包含Count。因此原池第一个候选有两份抽取权重，其余各一份，未改成均匀抽取。现代内核使用同一权重选择器执行，资料馆保留原候选顺序和权重。

## 本轮收录

- 人物初始属性、天赋、外功／内功／特技、装备、成长模板。
- 全量基线外功、内功、特技、奥义、道具、天赋与状态的原参数，保留修炼成长、装备要求和条件顺序。
- 地图、剧情、战斗站位、门派、商店、新手任务、全局触发、天关掉落、装备词条池、点穴与动作配置、资源引用及原版提示。
- 原字段中完整标识对应的正向、反向引用。关联引用用于查找资料，不代表已满足获得条件；对白与选择文案不参与引用识别。
- 上传包《鹿鼎记》78段完整原记录。其中39段与基线同名，39段为基线缺失；新增39段单独列为“补充剧情”，同名段保留版本对照，不覆盖基线。
- 上传包其他XML、官方早期XML、后期MOD模板XML及重制Excel的完整参考快照，保留字段、子节点／行顺序、文件SHA-256与来源版本。
- 后期10份Lua源文、43个分周目开局伙伴候选与旧C#调用依据；11个主要C#文件的摘要对照，用来识别与现有参考重叠的实现。

入口为首页“原版资料馆”、游戏菜单“资料”，也可直接使用 `?pack=jyx&view=library`。分类按需加载，支持全分类搜索、伙伴筛选、关联跳转和条目独立链接。旧伙伴条件图鉴保留。

## 可复现与后续缺口

正常 `npm run content` 只读取仓库内快照与原数据子模块，不要求另外三个参考仓库或上传包仍在本机。显式刷新快照时才需要：

```sh
python3 scripts/refresh-original-references.py \
  --references /workspace/references \
  --uploaded /workspace/.cloud-setup-jyxr/extracted/X-text-assets
```

刷新会核对三个外部仓库的固定提交。源快照位于 `reference-materials/`，生成的可浏览数据位于 `public/data/library/`，`manifest.json`列出版本、文件摘要、不同ID与异名。

下一步优先核对《鹿鼎记》同名段的分支差异及上传地图入口，补足双儿定义依据后再接入缺失剧情；随后核对后期公式与其余Lua覆盖、尚未完整实现的天赋／奥义效果。周目伙伴奖励接入不代表剧情招募路线全验，也没有提高整体通关率。
