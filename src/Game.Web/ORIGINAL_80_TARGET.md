# 原版 80% 目标验收

目标保持为现代 HTML5 原版重建，西方章节暂停扩展。此前 40%～50% 是工程粗估，
没有精确的全游戏完成率分母。以下作为推进到约 80% 的实用验收门槛；不会把源码行数、
结构转换数量或测试数量直接相加成完成率。

| 验收范围 | 当前证据 | 仍需完成 |
| --- | --- | --- |
| 浏览器与内容配置 | 真实 C# WASM、Phaser、两包隔离、原素材资源引用 | 持续验证资源与发布 |
| 一周目开局 | 36 个答案效果源码对照，问答／24 头像／重摇／奖励／存档 | 与后期成长继续回归 |
| 新手与门派 | 六阶段教学、九个门派入口、实际战斗与奖励 | 扩大门派中后期路线实玩 |
| 人物与物品系统 | 装备、心法、秘籍修炼、药品与交易；队友培养、加点、后备和原地点仓库已通过浏览器验收 | 完整剧情道具流程 |
| 主线连续游玩 | 正常问答开局至八人队、20 级、29 场战斗；黑暗的阴影胜利、神秘剑客原失败分支继续；原结局、周目继承独立验证 | 从正常成长继续到组织、紧急、华山及结局；完整剧情道具流程 |
| 特殊玩法 | 竞技场、天关、试炼、珍珑和洗练接入；轻功／点穴可玩；原四场华山到 True Ending 的隔离高属性流程及真实失败通过 | 扩大正常难度路线及多轮奖励实测；隔离流程不是 Boss 平衡验收 |
| 战斗一致性 | 47 项源码选定规则对照，15 个常用天赋和两种 Buff 新装配；心眼致盲免疫，浏览器实际队友用药；153 项相关测试通过 | 扩大反击／免疫及区间修改组合、时间限制、复杂技能收益与原 AI 差异 |
| 发布与持久化 | 旧 v1／v2 浏览器存档、跨包拒绝、窄屏、实际文件导入导出；77 项浏览器检查通过，源码媒体取消跟踪及提交检查通过 | 扩大中后期长流程存档回归 |

只有主要玩法可连续游玩、关键规则有对照、以上缺口达到可接受覆盖后，才报告接近 80%。
目前不能把“接入特殊玩法”当作“原版后期已经通关”。隔离高属性或替换木人对手的测试
用于验证接口和状态回写，明确不作为原版 Boss、难度或全路线通关证据。

素材约定：新图片、帧图集、音频、字体及素材包不再提交 Git。源码只保留资源索引、
来源说明、提取／恢复脚本和校验锁；本地媒体另行打包。线上暂复用此前已经部署的素材，
发布检查禁止上传新增或改动的素材内容。旧提交历史不进行破坏性重写。
