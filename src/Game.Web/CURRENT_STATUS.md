## 现代界面

- 地图首屏固定六个常用入口：人物、装备、修炼、行囊、队伍、更多；保存、通知放在顶部。手机无需横向滑菜单才找常用功能。
- 资料馆、伙伴图鉴、设置、读档、选世界、指南和开发记录集中在“更多”；任务仍有地图上“当前章节”直达入口。
- 减少大标题、角色卡和准备区的占地；地图地点采用紧凑网格，保留阅读和触摸尺寸。战斗保留独立的走位/选招/行囊/调息/暂停栏。
- “更多”在对话、商店和战斗等不稳定阶段禁用读档/切世界，保存仍受真实状态限制。

## 通知与操作记录

旧“旅途记事”只记录剧情记事，战况短日志只显示最近战斗，二者都不是完整操作历史。

现在订阅真实GameSession事件记录获得物品、升级、称号、伙伴加入/位置变化/离开和剧情提示；同时记录对白、流程日志、战况与成功执行的管理/交互命令。通知有未读角标，历史支持文字查找和分类。失败反馈和保存成功等浏览器提示另列，明确只留在当前页面。

每个旅程有独立ID，最近300条随手动或自动存档保存；旧存档没有历史时从当前读档开始记录，不伪造以前发生过的操作。导入前校验记录长度、顺序、类型和时间；坏记录不会替换游戏。自动回合与继续对白不重复写无意义命令，实际战况和对白照常记录。

不是所有规则变化都有独立事件，例如每项Buff内部计算过程尚未逐项持久记录；不能称为全部操作的永久审计日志。300条之前的记录会移除。
