# 原版内容的现代化重制

用户已选择现代化重制。本计划是接下来的开发与验收依据；此前的原版迁移、90%阶段记录和规则差异继续保留，不能把历史百分比当作现代化版本的完成度。

## 内容边界

- 保留已接入的人物、剧情、地图、道具、武学、招募条件及原素材；保留伙伴图鉴、155条路线图及地图前置提示。基础数值暂不整体重平衡。
- 继续使用TypeScript/Phaser界面与C# WebAssembly规则内核，不运行旧DLL。旧资料只用于对照与导入。
- 当前有格子的集气战棋与手动、自动操作保留；无格子即时战斗属于另一个玩法设计，不在本阶段改造。
- 旧随机调用顺序、Unity粒子逐个复刻与已证实无实际玩法价值的旧缺陷不作为发布前提。伤害、保护、反弹、死亡和奖励必须有明确、一致、可验证的规则。
- 缺来源的双儿及两类木人、额外版本补充入口继续归档为可选内容，不为凑完整度猜造数据，也不删除已接入的后期伙伴池。不将双儿的NPC管理用途视为已查证事实。用户提到的V43.0暂不扩展，不在未确定对应内容前批量删除资料。
- 西方试验章保持现状，优先完成原版内容下的现代化体验。

## 必须继续解决的实际问题

- 正常26级队伍的最终战曾失败；需要先区分难度、成长路线与规则缺陷，不通过强改胜负或一律削弱敌人处理。
- 多目标、自伤、分伤、濒死与复活要确定现代规则下的顺序，避免错扣资源、重复奖励、死者继续行动或卡死。允许与旧代码不同，需说明影响。
- 缺来源的天赋效果不算已实现；需要设计时，单独记录为重制规则。剧情缺引用、隐藏时限及实际无法触发的路线继续排查。
- 无悔实时战斗/交互存档仍未实现，不能把普通自动存档称作无悔模式。

## M1实现说明

四种界面状态由当前队伍位置和已有的玩家后备资格计算，不新增存档格式：玩家安排后备与剧情离队仍走不同服务。每类显示人数、说明和适用操作，参战队员装备与武功详情可展开。剧情暂离仅表示目前不能由玩家召回，不保证将来一定重新加入。

本轮Release构建与类型检查通过。原生管理回归验证实际招募/随行、换装、修炼、后备归队和存读档；额外的隔离剧情离队分支检查召回资格撤销与读档保留。

浏览器共71项检查通过：新手主流程37项、管理专项9项、开发记录7项、已有自动存档/特效9项、音频/档案专项9项。管理专项覆盖四种分组、装备实例保留、真实参战、剧情离队禁止召回与手机布局。人物查看后恢复选择，完整对比状态，区分视图可用性变化与游戏数据变化。

新手主流程保留真实音频播放；只将发生在实际清空音源操作前后2秒内、同一原版媒体URL的`net::ERR_ABORTED`记为预期取消，其余请求失败与HTTP错误继续使测试失败。音频专项另验证真实MP3解码。首次取消请求告警及最终通过记录均保留，不将程序主动释放旧曲目误判为文件缺失。

这批不代表完整通关，正常最终战失败和无悔实时存档缺口继续保留；此前的[90%历史交付](ORIGINAL_90_MILESTONE.md)不是现代化重制的完成度。
