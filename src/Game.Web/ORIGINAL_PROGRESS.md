## 本次补齐

- 新增14项原天赋配置，包括大小姐、自我主义、夫妻同心、奋战及三个追加攻击天赋。
- 大小姐与自我主义按原单精度计算人数奖励，人数包含自己，上限10；同有两者时只取自我主义。
  每个存活持有者对其他队友施加一次0.9攻击乘数，多个持有者叠乘；不影响敌方。
- 幽居、素心神剑、左右互搏、醉酒和神速攻击先合并概率，再分别判定追加攻击；
  神速最多追加两击，倍率0.6/0.3。尊重Buff插入顺序及遇神速后停止累加的原行为，避免多个Hook重复执行。
- 夫妻同心要求存活、同队、异性且同有天赋的伙伴；分别随机加强攻击区间或防御。
- 217项隔离源码组合检查通过，另保留81项后续规则、57项首战及常用规则检查。
  这些检查不是自然获得天赋、完整随机序列或全路线通关的证据。
- 增加环境明暗、行动聚光与真实受击/治疗柔光。支持关闭、减少动态及暂停，继续复用原素材。
  光照不参与命中、HP、行动条或胜负计算；不是原Unity灯光的逐像素复刻。

追加攻击仍有边界：现代正伤害命中后执行与旧版负伤害回复、特殊伤害、伤害夹限、
死亡反应及原先“附加Buff之后”的时点还未全量对照。源代码的Buff拼写“左右互博”与数据中的
“左右互搏”不一致，本次没有把两者偷偷合并。阉人的暴击覆盖与后续加减暴击的顺序也尚待完成。
完整要求继续以 [完整复原清单](ORIGINAL_RESTORATION_TARGET.md) 为准。

## 原版的优点

自由武学、伙伴培养和门派分支构成了重玩动力。剧情、物品、招募和战斗相互影响，
同一批系统能够支撑不同队伍和路线；这些值得保留，也适合以后独立内容包复用。

## 当前问题与建议

| 观察到的问题 | 改善建议 | 顺序与边界 |
| --- | --- | --- |
| 前置条件和时限隐藏，常常不知道下一步去哪 | 旅途记事给出已经发现的线索、时限和可行动地点 | 优先做可关闭辅助，不改原奖励和分支 |
| 升级不必然解决卡关，失败原因难以判断 | 战况显示天赋、连击、免疫、克制及治疗来源 | 先完成真实规则，再解释真实结果 |
| 换人、装备、运行心法与秘籍管理分散 | 一个战前整备入口统一这些操作 | 保持角色实例及原穿戴、修炼限制 |
| 自动战斗对控制、全场治疗及自伤评价不足 | 提供保命、治疗、控制的优先级设置 | 继续称现代AI，不宣称原AI复刻 |
| 多人棋盘拥挤，技能与状态不易读 | 保留柔光和静态模式，后续增加目标检查及镜头缩放 | 不用强闪光遮挡格子和操作 |
| 当前后期验证不足、尚有规则和演出缺口 | 按正常队伍完成最终战、华山及周目，再评价整体平衡 | 隔离高属性通关不能代替正常流程 |

以上是阶段性体验建议，不提前扩展西方世界。原版完成后，再据实际完整流程形成下一版设计结论。
