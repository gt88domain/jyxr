# 伙伴图鉴与招募条件

首页“伙伴图鉴 · 加入条件”、游戏菜单“图鉴”、队伍面板以及分项进度页均可独立打开图鉴。
链接参数 `?pack=jyx&view=companions` 可直接打开图鉴，`view=progress` 可直接打开分项进度。
按姓名、角色形态、地点和剧情关键词搜索，或筛选当前参战、随行、后备及待验证角色。
使用原头像，不生成或上传新素材；图鉴只读，不直接授予角色，也不执行地图事件或随机条件。

当前来源为固定 X XML 数据 `b41198219087858ece19d5484f5061e0289c47bc`，
覆盖65个角色形态、80条JOIN/FOLLOW指令、155条不重复经过剧情段的地图入口路径。
同一个人物可能有多个形态，多种招募方式也不代表多个独立伙伴；其中包含测试和特殊演出参考。

## 条件展示

每条路线分别列出地图、交互地点、显式条件、概率、一次性入口、战斗／点穴、费用、时间变化与对话选项。
同一个返回结果下更早的条件分支也予以保留，避免把兜底JOIN误写成无条件招募。
多个前置条件的否定不会拆成各自的否定；只有单独道德比较才提炼为局部数值区间。
原事件的优先级、重复记录与概率仍决定实际能否进入，图鉴不声称当前立即可招募。

例如，令狐冲的入队分支前有道德≥65及道德<35两条拒绝分支，因此实际范围是35≤道德<65。
原生测试经真实华山后山交互验证34拒绝、35加入、64加入、65拒绝。
田伯光胜利和失败后的加入分别列出；王语嫣保留四个加入段。
女主有三个FOLLOW段和一个JOIN段，随行与参战明确区分；程英初级／高级也保留为不同角色形态。

原故事包含角色离队／结束随行时，图鉴单独列出相应记录。
当前位置从真实roster读取；曾加入的证据从当前存档已完成的原加入段推导，
不额外写收藏存档，不因阅读图鉴触发招募或完成剧情。女主的当前自定义名字也会显示。
