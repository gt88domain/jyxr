## 仍未完成

- **139 段剧情、43 个地图事件和 2 个世界触发被隔离**，含直接错误及其上游依赖。主要缺口为点穴／轻功等小游戏、竞技场／天关／华山／珍珑／试炼／洗练、通关与下一周目 UI、女主命名流程；另有丢失的天赋、称号、地图和两个木人角色引用，以及原 XML 的指令拼写／空对白问题。
- **剧情和世界没有全量实玩**。结构检查只证明已转换的指令及显式跳转引用闭合，不证明每个条件分支、角色在队前提、限时任务和后期战斗都符合原版。
- **战斗规则尚非原版全量等价**。首战补齐的规则见 [战斗对照](../Game.Web.Runtime/BATTLE_PARITY.md)；大量天赋／Buff 定义只有描述或部分规则，AI、行动条与随机序列也仍有差异。不能把导入定义数当作效果完成数。
- **系统界面仍有缺口**：完整开局问答／摇点、属性分配、仓库、队伍编排及后备队员管理、特殊玩法和完整剧情道具使用尚需逐项接入。
- **演出仍是替代素材**：保留原创图，不复制旧版图；大部分地点与人物复用占位美术，尚无原版音频／动画。原版时间／位置规则已使用现代 Core 实现，尚未与旧程序做逐帧或同种子回放对照。
