## 人物管理与特殊玩法接入

人物面板可选择参战队友，真实分配升级属性点、穿卸装备、选择内功与秘籍修炼。
每本秘籍最多供一名角色同时修炼；参战角色在真实结算时获得对应修炼经验。
玩家主动转后备的角色保留同一个人物／装备实例，可存读档后召回。剧情安排的随行或离队角色
不能通过编队强行变为参战队员；剧情离队会撤销玩家召回资格，并按既有服务归还装备。
原松鼠旅馆箱子包含首次介绍与后续存取，容量、任务物品限制、装备实例和数量均由 ChestService 管理。

竞技场、天关、试炼、珍珑、洗练使用现有 Application 服务；浏览器提供必选／禁选／人数受限的
参战选择、实际战斗和结果回写。女主命名等待实际输入，姓名与随行状态可存读档。
同福客栈升级使用原 100 两／10 天费用与实际 LevelUp；洗练显示真实候选、消耗元宝，保存真实词条。
规则层测试包含原战斗数据与隔离高属性输入；额外木人对手用于稳定验证胜利回写，
明确不算原版 Boss 或整个后期章节通关。

同福客栈轻功与葵花点穴手已接入实际小游戏，保留原十两费用、月度冷却和
Application.MiniGameService 的奖励、唯一奖励标记、练习点与身法／臂力成长。
轻功沿用四个反弹头像、300 初速和每 0.2 秒加速 1%；碰撞结束。
