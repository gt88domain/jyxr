# 下一版的阶段观察与建议

原版尚未完整验收。以下是依据当前源码、资料迁移、已有正常旅程和针对性检查形成的阶段观察，不冒充完整通关后的结论。西方章节继续暂停，先完成原版。

## 值得保留的东西

- **自由武学与伙伴构筑。** 门派、武学、内功、装备和天赋共同决定战斗选择，长期培养比单纯换更高数字的装备更有吸引力。
- **剧情给成长赋予意义。** 招募、学武、救治、获得物品和角色关系相互影响；奖励不应脱离玩家刚做过的事。
- **分支与周目。** 正邪选择、不同伙伴和奖励池提供重玩理由，但应让玩家理解选择会影响什么。

## 原版暴露的问题，以及下一版怎么改

| 观察依据 | 问题 | 下一版可验证的改进 |
| --- | --- | --- |
| 招募图鉴需展开前置、时限、道德范围和更早分支 | 条件藏得深，玩家难以判断该去哪 | 记事只提示已经获得的线索和明确时限；完整攻略图鉴保留可选入口 |
| 已有正常26级队伍完成救援后仍败于最终战场 | 只告诉玩家升级，不能解释构筑为何失败 | 战况解释伤害、免疫、控制、治疗和死亡来源；战前可比较装备／心法／队伍变化 |
| 装备、修炼、参战与后备分散在多个面板 | 整备成本高，容易漏设置 | 一个战前整备页显示队伍、装备、主内功、修炼秘籍和药品；提交时仍调用同一套真实服务 |
| 八类门派加成作用于最终伤害，且逐步截断 | 看似相同的乘法，执行阶段不同就会改变结果 | 明确规则阶段、来源和顺序，用独立公式检查保护；避免把复杂规则藏在界面代码里 |
| 原随机函数含上界再取模，首个候选权重翻倍 | 随机实现细节成为隐蔽玩法；表现抽签还会影响随机序列 | 新游戏用明确的权重表，显示会影响决策的概率；战斗与表现分开随机流 |
| 人物有剧情引用却缺定义，天赋有描述却无效果 | 文字与实际行为脱节，后期补内容难发现缺项 | 内容发布前检查引用及可执行效果；编辑器明确区分已实现、部分实现和仅资料 |
| 当前自动策略尚未完整估计治疗、控制、自伤与联动 | 自动出招未必符合玩家意图 | 先做保命、稳健、进攻三种清楚策略，用相同局面比较结果，再考虑复杂自动配置 |

## 西方试验章将来怎么做

原版完整后，再用共用引擎做“低魔世界＋佣兵冒险＋自由战技修炼”。角色、地图、剧情、道具和美术另配，避免复制第二套战斗与存档实现。

第一步仍控制在一个营地、一个野外区域和一次小型探索：招募两名职责不同的佣兵，一次补给选择，一项可自由训练的战技，一场能用不同队伍思路解决的战斗。优先判断整备是否清楚、探索是否有取舍、失败原因是否能理解，再扩大世界。

建议第一章暂不堆大量职业、法术和技能树。先证明少量组合有不同用途，再增加内容数量。生成美术应围绕统一的人物比例、战场可读性和动作规范制作；素材数量不作为玩法完成度。
