# 浏览器双内容包

## 当前优先：原版江湖

`legacy_world.py` 在此前入门体验之后接入批量原版迁移。固定基线共 1,887 段剧情、162 张地图、1,120 个地图事件、393 场原版战斗（另有 1 场明确新编的结伴练习）。当前 1,787 段原剧情完成结构转换及跳转依赖闭合，162 张地图、1,097 个原事件、19 个世界触发与全部 6 段 `newbie.xml` 任务已接入。100 段剧情和 23 个原地图事件被隔离，其中包含依赖缺口的上游剧情；这不是通关验收数字。

`public/data/original-migration-audit.json` 列出每段隔离原因、源文件和依赖目标；`original-story-source.json` 完整保存 1,887 段原始指令及条件，明确作为源资料归档，不是可执行 DSL。原文本、选项顺序、奖励和条件均来自固定 XML。遇到未知指令、错误拼写、丢失引用和未实现特殊流程时不生成成功空操作，也不暗改奖励绕过。

九个门派／无门派选择执行原入口剧情。少林的 `MENPAI` 位于 `SELECT` 之后，转换器先执行余下动作，再按选择分支跳转，保证门派写入不丢失。头像／模型 ID 保存到角色状态，界面读取对应的原版媒体。大地图使用 Core 的坐标距离、行程时辰与位置记忆；旧浏览器大地图存档缺少位置时只补初始坐标，不回血、不清档。随机地图事件采用当前展示的事件快照，读取状态和实际点击不会重新抽取另一事件。

`legacy_creation.py` 为金庸包配置一周目七组问答、24 个头像与初始奖励。36 个答案效果由 `tests/creation-source-parity.py` 对照固定 `RollRoleUI.cs`；C# 宿主负责生成候选、回退、重摇和最终确认，UI 不接收可任意注入的角色属性。重摇只替换候选，不向正式背包发奖；确认后属性、物品和外观使用现有存档序列化。已有浏览器存档不追补新开局奖励。原始 `createCharacter` API 保留模板构建，供旧存档／战斗回归夹具使用；正式金庸新游戏按钮进入问答。

教学任务按 `newbie.xml` 的原完成条件自动衔接，始终只保留一个活动阶段；原版赠药本身即满足第一任务完成条件，不改成强制实际购买。旧的明确新编结伴练习继续保留供存档衔接。昆仑派原数据没有地点与出口，单独增加 `browser-empty-map-exit` 防止玩家被困；不冒称原事件。

下面的六地图／37段说明记录上一轮入门体验，当前地图与剧情范围以上述批量迁移及审计为准。西方包维持原样，暂停扩展。

在仓库根执行 `python3 src/Game.Web/scripts/build-content.py`。只需 Python 标准库与已初始化的 `jyx-legacy-data` 子模块；不修改子模块。`browser_packs.py` 组装金庸新手章节，`build-frontier.py` 创建原创西方试验章，两者都输出实际 `ContentPackage` 定义与 DSL v3 剧情。

- `public/data/packs/index.json`：内容选择清单，`url` 相对 `data/`，默认 `jyx`。
- `public/data/packs/jyx/content-package.json`、`frontier/content-package.json`：两个独立运行包。顶层 `browser` 是界面、入口、素材和目标配置，载入 Core 前由宿主分离。
- `public/data/content-package.json`：与 `jyx` 包相同，保留旧首战验证入口。
- `public/data/starter.story.json`：原有 14 段开场/武师迁移基线，不混入新增章节。
- `public/data/starter-world.json`：25 段旧指令与 3 张地图的原始投影，可核对出处、顺序及条件。
- `public/data/starter-dialogue-excerpts.story.json`：对白查阅摘录，不作为完整剧情执行。
- `public/data/legacy/`：转换器完整原样导出，不表示整份世界已经可玩。
- `public/data/content-build-report.json`：计数、来源提交、首战规则适配和未迁移范围。

## 金庸新手章节

原 14 段流程及原第一战保留：`新手村_出生` → `南贤屋内` → 南贤开场 → 获得一本《内功入门》 → `小村/武师` → 选择第 0 项 → `新手村_武师7` → `南贤居_木头人_战斗`。原主角/木头人位置是 (2,2)/(8,2)，首次战后银两仍是 10；没有凭空塞入开局装备。

随后可在人物功法中选择秘籍修炼，找南贤选择出村并接受原教学：`新手村_南贤_出村` → `original_教学开始` → `original_新手引导.开始` → `original_新手引导.任务买药`。原对白和 300 两教学款均来自同一版本 XML。原来的“不做教学，直接闯江湖”跳到尚未迁移的门派 UI，本章明确关闭该选项，不假装门派流程已经执行。

大地图当前开放洛阳、万劫谷和南贤居。洛阳首次商人事件保留原赠武学类型选择与 5 颗小还丹；赠送物品不算购买。再次进入商店才调用真实 ShopService 交易，原价粗布道袍 150、小还丹 50。粗布道袍没有穿戴门槛，适合完成购买、装备、卸下和卖回的体验。

万劫谷首次与钟灵交谈，选择“义不容辞”即执行原 `tlbb.dy_钟灵找` 的 `JOIN`。这条原剧情没有点穴或战斗前置；找闪电貂的后续事件尚未开放。没有把另一条田青文的战斗/点穴剧情跳过后冒称已完整招募。

返回南贤居可进行 `browser_结伴练习`，这是明确新增的两人对原木头人的练习，随后可查看章节回顾。原 `南贤居_经验木头人_战斗` 引用了数据包中不存在的角色 `经验木头人`，因此没有将它的四敌布局直接改名后声称完整恢复。`browser_*` 段落是新编内容，不属于原版对白或奖励。

本章对 `NEWBIE` 显式映射 `newbie_*` Boolean flag；对应买药地图事件用 `has_flag` 判断，避免沿用参考转换器的 `false` 占位。教学款领取后关闭原出村教学入口，防止重复刷钱。其他未支持的地图事件不会出现在当前地点列表。

## 原创西方试验章

`frontier` 为原创中文低魔佣兵故事《灰烬边境》，没有复制金庸角色改名。只共用规则、AI、物品、商店、剧情与存档引擎；角色、成长、战技、商品、地图、剧情和素材通过独立数据配置。

流程为：灰烬渡口营地接委托 → 获得旧剑、稳息笔记、2 份敷药和 80 银币 → 装备/修炼 → 军需摊交易 → 邀请斥候玛拉 → 荆棘旧道路障战 → 黑鸦废塔两敌战 → 取得封蜡账册 → 返营领取 120 银币。护衣 45、敷药 15、步进斩操典 35，操典最多购买一次。废塔入口要求突破路障且玛拉在队；战败会返回营地，可整备重试。领奖事件和奖励 flag 双重保证仅发一次。

这条路线为有限的试验章，不表示已有完整西方开放世界。约 20 分钟是新手章节的体验设计目标，实际时长取决于阅读、探索、手动或自动战斗，不用测试脚本耗时冒充玩家时长。

## 规则与素材范围

`starter_rule_effects.py` 仅装配有旧源码依据的首战必要项：瘸子移动 -1、异世人低血阈值、攻击强化数值、打鸡血怒气。它有独立审计/验证，不代表所有 157 个天赋与全部 Buff/Hook 已复原。随机词缀公式来自旧 `ITTrigger.cs`，数量概率来自 `Item.cs`；正负 Buff 分类出处见构建报告。

金庸包通过 `legacy_media.py` 将固定基线的资源 ID、规范化路径和用户上传 X1.0.0.1 包的实际媒体路径显式关联。`browser.media` 提供地图、背景、头像、物品和角色动画；运行时按当前角色的模型／头像解析外观。提取后的原图片与帧图集保存在 `public/art/legacy/`，普通内容构建不需要 UnityPy；仅重新提取时使用 `requirements-art.txt` 中锁定的依赖和用户上传包，步骤见该目录 README。

上传包只作为本次媒体来源，其剧情和额外鹿鼎记记录没有混入固定子模块规则基线。`legacy-art-coverage.json` 列出引用覆盖、模型缺口和动作时序限制。西方包继续使用独立原创图片。
