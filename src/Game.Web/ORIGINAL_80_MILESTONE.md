# 原版80%阶段交付

本阶段继续使用现代C# WebAssembly与HTML5前端，不运行旧DLL，也不扩大西方内容。这里的约80%是工程估算，六类加权值为77.75，按既定规则取整到5%；不是精确测量、通关率或全行为等价声明。

## 相比上一阶段实际补入

- 真武七截阵按支援者逐步增伤截断、包含等号的挡伤概率及float 30%伤害；五行按重定向后的目标寻找异角色支援，全员等分且丢弃余数；八卦80%/20%分别截断并保留首候选双权重。
- 金刚伏魔圈禁止移动、至少三名存活成员增伤，不足三人破阵并移除已学天赋。原BattleField:1614会移除已死亡sprite，现代保留死亡记录，因此候选需过滤已死单位；同一次原回调中尚未确认死亡的时间差仍待核对。
- 新接24项普通天赋规则，加上3种阵法，共27项从元数据转为部分实现。另将慕容世家列为斗转星移的联动条件。当前158项中76项配置、71项部分实现、5项条件联动、5项仍查证、1项黑衣身份；147项配置不等于147项全部等价。
- 包括斗转星移HP反弹、闪避反击、追魂、无形剑气、黑天死炎最低伤害、攀云乘龙、死生茫茫生命上限吸取、玄门罡气、内功专属联动、伴侣条件、随机减益和奥义后续效果。易容、溜须拍马、魔神状态接入普通战斗行为。
- 从上传X1.0.0.1的audios数据束转换183段音频为MP3，精确路径或唯一文件名绑定全部166个原音频资源ID。按需加载场景/战斗音乐与真实SkillCast音效；手势解锁，音乐/音效独立调节和保存，切换曲目和世界时释放旧音频，后台暂停。
- 玩家档案独立存于IndexedDB，按世界隔离；称号、技能上限、已用奖励键、元宝和统计可跨新旅程保持。旧版仅存于旅程槽的档案在允许新游戏前先迁移，无需先按继续。继续旧旅程采用当前设备档案，不相加发奖；显式导入完整备份则恢复备份中的档案，界面已说明差别。异常/未来版本拒绝替换；损坏记录保留并阻止自动覆盖。
- 内容与WASM并行加载；网络错误及502/503/504只自动重试一次，其他HTTP错误直接报告。运行时加载失败解除失败Promise缓存，保留重新载入入口。

## 验证证据

- 224项新增隔离规则检查，包括实际施法的分伤、重定向、破阵/移动、反击、float/取整、MP绝对差、生命吸取及集气。既有奥义、范围、属性、控制、门派和生存检查也通过。
- 28项设备档案检查：新角色、旧旅程保留、重复读取不重复加元宝/技能上限、显式备份恢复、跨世界及失败替换边界；未确认问答草稿不提前写入空档案，首次旧档加载仍迁移其原档案。
- 浏览器阶段检查通过：故意返回一次503后恢复；原MP3实际解码；音量/移动端；旧旅程和新人物继承档案；跨世界隔离；真实原战斗事件调度音效。媒体播放调用被记录，解码用真实MP3，不声称进行了扬声器听感验收。
- 源数据核对和183段音频对应的去重文件哈希通过，剧情/原资料馆保持5493条原始记录，不用运行适配数据覆盖原资料。
- 通用.NET回归918项通过；完整919项运行中，`MediaReferenceResolverTests.JsonLoader_LoadsRealBaseModWithUnifiedMediaReferences`因本地未提供`mods/jyxr-base`而失败。该检查未被删除、跳过或算为通过；HTML5内容包另有实际加载、构建与浏览器验证。
- 按要求没有新增正常路线或整条通关测试；旧26级队伍的最终战失败记录继续保留。
