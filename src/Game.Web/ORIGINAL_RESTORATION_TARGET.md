# 原版完整复原验收

当前目标由约80%改为完整复原，原80%清单保留作历史阶段记录。完成率没有可信的单一分母，
只有以下范围全部满足，才将本工程标记为“原版完整复原”。不以条目数量、素材引用覆盖或某场胜利代替行为验收。

基线仍为已固定的 X 数据及配套旧 C#，上传 X1.0.0.1 用于补充缺失证据；不同版本的差异逐项记录。
现代 C# WebAssembly 与 HTML5 显示层继续使用，手动与现代自动战斗共用规则。西方章节暂停。

| 范围 | 完成要求 | 当前主要缺口 |
| --- | --- | --- |
| 开局与培养 | 问答、难度、门派、成长、秘籍、装备、伙伴和后备可连续使用 | 原完整天赋效果、复杂角色转化、长流程成长回归 |
| 原剧情与引用 | 全部适用剧情、地图事件和全局触发可执行；奖励、失败和时限忠于所选原基线 | 两类木人缺少定义、黑龙潭一处非法事件类型；五毒引用已按上传源修正，两句卓一航原文保留为无署名对白；其余结构仍需路线实玩 |
| 战斗规则 | 全部实际使用的天赋、Buff、特技、内功、招式与奥义有效；数值、范围、触发顺序和免疫有核对 | 大量天赋元数据；特技已补配置但部分行为仍缺；多次攻击、直接伤害管线、反击免疫与组合顺序 |
