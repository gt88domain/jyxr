# Source and scope

Source code: https://github.com/gt88domain/jyxr/tree/html5-web

This is a browser-playable prototype with a Jin Yong beginner chapter and an
original low-magic mercenary chapter, not a complete game or exact combat port.
Both content packs share the C# engine and have separate browser save slots.
The C# rules and browser host source are available on the branch above.
The repository's GPL-3.0 license and the original notices apply to its code.
Original story, data and artwork retain their respective upstream notices and
terms. The Jin Yong pack now uses artwork decoded from the user-provided X1.0.0.1
archive. See art/legacy/README.md and manifest.json for provenance and hashes.
The western prototype retains its separate generated artwork.

Media payloads are maintained separately from source Git. The source retains
resource indexes, provenance and a SHA-256 bundle lock. Existing website media is
reused while code is updated; original submission history has not been rewritten.
