# Source and scope

Source code: https://github.com/gt88domain/jyxr/tree/html5-web

This is a browser-playable prototype with a Jin Yong beginner chapter and an
original low-magic mercenary chapter, not a complete game or exact combat port.
Both content packs share the C# engine and have separate browser save slots.
The C# rules and browser host source are available on the branch above.
The repository's GPL-3.0 license and the original notices apply to its code.
Original story and data retain their respective upstream notices and terms;
newly generated scenery is separate from the legacy image assets.
